01.

Introducción

LolPlusTV utiliza una arquitectura modular extensible que permite desacoplar la aplicación nativa del descubrimiento e ingesta de metadatos o reproducciones. Un addon es un paquete distribuido externamente (alojado habitualmente en repositorios de GitHub) que expone sus capacidades mediante un manifiesto estandarizado.

El sistema se basa en el principio de separación de responsabilidades:

Catálogo

Responde a la pregunta: "¿Qué contenidos existen, qué sinopsis tienen o cómo se ordenan?"

Fuente

Responde a la pregunta: "¿En qué servidor o stream puedo reproducir esta película o episodio específico?"

02.

Tipos de Addons

El motor distingue tres tipos fundamentales de módulos integrables:

Fuente (Source)

Obtiene servidores, embeds o enlaces manifest (.m3u8/.mp4). Implementa las funciones clave getStreams() y opcionalmente extract().

type: "source"

Catálogo (Catalog)

Proporciona listas dinámicas para la pantalla principal, búsqueda general, descubrimiento por géneros y metadatos con getHome() y search().

type: "catalog"

TV Live

Suministra señal de canales lineales de televisión en directo categorizados por regiones o temáticas. Basado en estructuras JSON o enlaces M3U.

type: "tv"
03.

Instalación y Resoluciones de URI

Los desarrolladores e instaladores pueden ingresar un identificador corto tipo GitHub o una URL completa. El motor de resolución interno procesará el endpoint para localizar el manifiesto ejecutable. 

usuario/repositorio
usuario/repositorio@main
https://github.com/usuario/repositorio
https://github.com/usuario/repositorio/tree/main
https://raw.githubusercontent.com/usuario/repositorio/main/index.js
Contexto de instalación: El apartado de la aplicación desde el cual se realiza la instalación dictamina su registro contextual principal (Fuentes vs Catálogos).

Estructura Recomendada del Proyecto

Un repositorio estándar debe presentar un árbol limpio con el archivo de configuración y la entrada JavaScript raíz.

Project Tree

05.

manifest.json Specification

El archivo manifest.json declara la metadata, requerimientos y permisos del módulo ante el runtime de LolPlusTV. 

{
  "id": "mi-fuente-oficial",
  "name": "Mi Fuente HD",
  "version": "1.0.0",
  "description": "Proveedor de servidores HD para películas y series",
  "type": "source",
  "author": "Desarrollador",
  "logo": "https://ejemplo.com/logo.png",
  "entry": "index.js",
  "supportedTypes": ["movie", "tv"],
  "capabilities": ["resolve"],
  "mode": "vod",
  "apiVersion": 1
}
Campo Tipo Descripción
idStringIdentificador único invariable del paquete.
nameStringNombre comercial del addon presentado en UI.
typeEnumValores válidos: source, catalog, function, tv.
entryStringArchivo de Script principal JS (por defecto index.js).
apiVersionIntegerVersión del contrato SDK (actualmente 1).

07.

Implementación de getStreams()

Esta función asíncrona es obligatoria en addons de tipo source. Retorna una lista con servidores disponibles. 

async function getStreams(tmdbId, type, season, episode) {
  if (type === "movie") {
    return [{
      url: "https://servidor.com/hls/" + tmdbId + "/master.m3u8",
      title: "Latino 1080p",
      quality: "1080p",
      provider: "MiFuente"
    }];
  }

  // Si es Serie de TV
  return [{
    url: `https://servidor.com/series/${tmdbId}/s${season}e${episode}.mp4`,
    title: "Subtitulado HD",
    quality: "720p",
    provider: "MiFuente"
  }];
}

module.exports = { getStreams };
08.

Objeto StreamItem

Estructura normalizada enviada al reproductor:

{
  "url": "https://cdn.servidor.com/hls/live/master.m3u8",
  "title": "Servidor VIP (Sin Publicidad)",
  "quality": "1080p",
  "provider": "Fuente Pro",
  "headers": {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"
  }
}
09.

Resolución con extract()

Si getStreams() retorna una URL intermedia o de incrustación (Embed iframe), la función opcional extract() resuelve la URL final antes de cargar el reproductor. 

async function extract(embedUrl) {
  // Scraping o llamada para obtener el stream directo
  return {
    url: "https://stream-directo.com/video.m3u8",
    quality: "1080p"
  };
}

module.exports = { getStreams, extract };
10.

HTTP Headers Personalizados

Útil cuando un CDN restringe reproducciones por Referer o Origin. 

{
  "url": "https://protected-stream.com/video.m3u8",
  "headers": {
    "Referer": "https://embed-provider.com/",
    "Origin": "https://embed-provider.com"
  }
}

getHome() — Vista Principal

Genera filas o carruseles temáticos en la portada principal:

async function getHome() {
  return {
    rows: [{
      id: "estrenos_populares",
      title: "Estrenos Destacados",
      items: [
        { id: "tmdb:movie:550", title: "Fight Club", type: "movie", poster: "https://..." }
      ]
    }]
  };
}

Soporte para M3U / M3U8

Un addon de TV Live puede enlasar directamente una lista IPTV remota en su manifest mediante el parámetro m3u_url. 

{
  "id": "mi-addon-iptv",
  "name": "Mi Lista IPTV",
  "version": "1.0.0",
  "m3u_url": "https://miservidor.com/lista_canales.m3u"
}

Diagnóstico de Errores Frecuentes

Fuente sin respuesta: getStreams() debe retornar siempre un Array. En caso de no encontrar streams, retorne un array vacío [] en vez de null.
Identificador inestable: Cambiar el campo id del manifest romperá las configuraciones e historiales de los usuarios instalados.
